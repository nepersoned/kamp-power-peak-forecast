## 1. 대회 요구사항

### 문제 ⑤ 원문 요지
> 제공된 생산 및 전력데이터를 활용하여 **향후 지정된 시간구간의 전력사용량을 예측**하는 AI 모델을 개발하시오.
> 또한 **예측오차가 크게 발생하는 생산조건**과 **최대전력 피크가 발생하는 주요 조건**을 분석하고,
> **생산일정 또는 설비가동 시점 조정을 통한 피크전력 저감방안**을 제안하시오.

출제 배경에 나온 전력 변동 요인: 설비 동시 가동, 생산량 변화, 제품 전환, 교대시간, 계절 요인. 결과로 최대수요전력 증가 → 전력비용 증가, 특정 시간대 부하 집중 → 생산운영 안정성 저하.

### 예측 오차의 바닥
- 같은 모델을 시드만 바꿔 5번: 테스트 MAE 6.15~6.48 → 앙상블과의 차이(0.17)는 시드 흔들림 범위 안
- **1시간 전 실측까지 입력으로 줘도 MAE 6.15** → 하루 전 예측(6.26)과 거의 같음
- 한 시간 안의 15분 값 편차가 평균 6.1 → 현재 오차가 이 노이즈 크기와 같음
- 남은 개선 여지는 평상시가 아니라 **휴무 후 재가동일**(8/9 일 MAE 36~39), **가동 개시 피크 과소예측**(08~11시 편향 +11~17)에 있다

## 6. 피크 판정·저감·해석

### 해석
- **SHAP 상위**: 직전 가동일 동시각 피크·전력 → 가동 종료 이후 여부 → 생산량(±1시간 평균) → 인원. 오프셋 포함으로 예측값과 정확히 일치하도록 분해(오차 10⁻¹²)
- **상호작용 상위**: 휴일 × 가동 종료 이후, 생산량 × 인원 (같은 생산량이라도 인원이 많을수록 수요가 더 오름)
- **DiCE 반사실**: 예측 ≥ 190인 테스트 7시간 모두 해를 찾음. 목표수요 아래로 내리려면 해당 시간 생산을 중앙값 **48%** 줄이거나 인접 시간으로 이동
- 그림 11종: 데이터 개요, 레짐별 프로파일, 테스트 예측, 시간대별 오차, SHAP 중요도·요약·의존도·상호작용·FN/FP 사례, 일 단위 위험 판정, 저감 예시

## 9. 앞으로의 계획

### 역할: 강화학습 × TabPFN, 서로 보완하는 구조

두 트랙은 **"예측 분포를 만드는 쪽"과 "그 분포로 결정을 내리는 쪽"**으로 맞물린다.

```
오성민 (TabPFN)                           배진형 (강화학습)
하루 전 예측 분포 ─────── ① 시나리오 ──────▶ 실시간 수요 제어 환경
 (시간별 분위수)                             (예측 + 불확실성으로 에피소드 생성)
        ▲                                             │
        └────────── ② 결정 기반 평가 ─────────────────┘
          "어느 예측기를 써야 피크를 더 줄이나"로
          TabPFN vs LightGBM을 MAE 밖에서 한 번 더 비교
```

- **① 시나리오 공급**: TabPFN의 예측 분포(분위수)를 강화학습 환경의 불확실성으로 쓴다. 지금 환경 후보(LightGBM + 잔차 부트스트랩)와 비교할 수 있다.
- **② 결정 기반 평가**: 같은 정책을 LightGBM 예측으로 돌릴 때와 TabPFN 예측으로 돌릴 때의 피크 감소를 비교한다. 예측 오차(MAE)가 바닥이라 차이가 안 보이는 두 모델을 **"현장 결정에 얼마나 도움이 되나"**로 다시 가른다. 5장 차별성의 핵심 이야기다.
- ③ TabPFN이 불확실하다고 본 시간대(분위수 폭이 넓은 시간)는 강화학습 정책이 보수적으로 행동해야 할 구간이 된다. 3장 오류분석과 4장 운영 절차를 잇는 고리다.

**배진형 — 강화학습 트랙 (3장 피크 조건, 4장, 6장)**
- 피크 발생 조건 분석: 시각·요일·생산량·인원·계절별 190 초과 빈도. 강화학습의 상태·보상 설계 근거이자 3장 재료
- 실시간 수요 제어 환경(gym 인터페이스)
  - 상태: 현재 시각, 오늘 누적 최대 수요, 남은 생산량, 앞으로의 예측·분위수
  - 행동: 이번 시간 생산 비율(예: 100/70/40%), 미룬 양은 뒤 시간으로
  - 보상: −일최대 수요 − 생산 미달 벌점 − 계획 변경 비용
  - 제약: 일 생산 총량 완수, 시간당 생산 상한(관측 최대치), 가동 시간대 안에서만 이동
- 비교 기준선: 무조치 → 고정 규칙(예측 ≥ 190이면 30% 미루기) → 탐욕 최적화 → 강화학습(PPO 등)
- 최대수요전력 기본요금 기준 비용 환산, 전날 경보 → 당일 제어 운영 절차
- 최종 예측 모델 정리(레짐 전환 LightGBM), 평가 항목 추가(운전 상태 전환 구간, 생산조건별 오차)
- README·requirements·제출 zip

**오성민 — TabPFN 트랙 + 통계 시계열 기준선 (1장, 2장 비교, 3장 예측 오류, 5장 불확실성)**
- TabPFN 하루 전 예측: 같은 분할·같은 피처로 레짐 전환 LightGBM과 비교
  - 휴무일은 기존처럼 중앙값 기저부하, 가동일만 TabPFN으로 대체하는 버전도 시험
  - CPU 추론 시간 확인. 학습 문맥이 크면 원본 행만 쓰거나 나눠서 처리
- 예측 분포: 시간별 분위수(10·50·90%)를 뽑아 실제 포함률 확인, 컨포멀 보정 결과(81% → 95%)와 비교
- 평가 항목: 전체 MAE + 운전 상태 전환 구간 + 피크 시간대(08~11시) 편향
- **SARIMAX 기준선** (2장 비교표의 "전통 시계열 모델" 칸)
  - 하루 주기(24) SARIMA + 외생변수: 가동 여부, 생산량, 인원, 요일·주간 푸리에 항 (주기 168을 직접 넣으면 너무 무거움)
  - 매일 자정에 다음 24시간을 예측하고 하루씩 미는 롤링 방식. 같은 검증·테스트 구간, 같은 표
  - 1~6월 복제 구간은 자기상관이 가짜라 원본 구간 위주로 학습하고, 복제 구간 포함 여부를 비교
  - 정전일(8/28~29)은 결측·더미로 처리. `statsmodels` 설치 필요
  - 기대: 전주 값(테스트 8.3)과 LightGBM(6.3) 사이. "머신러닝이 전통 시계열보다 얼마나 나은가"의 근거
- 변수 정의와 데이터셋 가이드북 요약(1장). TabPFN 입력 피처를 고르며 변수를 들여다보게 되므로 함께 맡는다
- 재현성: 가중치를 오프라인으로 불러오는 방법, 라이선스 확인

**채택 기준 (TabPFN)**: 아래 중 하나라도 수치로 보이면 채택, 아니면 "시도했으나 기여 없음"으로 기록
- 전환 구간 또는 피크 시간대에서 LightGBM보다 뚜렷이 낮은 오차
- 보정 없이 명목 포함률(90%)에 가까운 분위수
- 검증과 테스트 **양쪽에서** LightGBM과 섞었을 때 개선
- 결정 기반 평가(②)에서 피크 감소가 더 큼

**TabPFN이 막힐 경우**(설치·속도·라이선스): 오성민 님은 파생 피처·날 단위 증강으로 전환하고, 재가동일·피크 시간대 같은 약점을 겨냥한다.

### 함께 지킬 규칙
- 평가는 원본 구간(7월 이후)만. 무작위 교차검증 금지
- 증강은 학습 구간 안에서만. 복제일 포함/제외를 비교해 기록
- 테스트 구간(8/16~9/14)은 선택에 쓰지 않는다
- 새 피처는 `src/features.py` 함수로, 증강은 학습셋 변환 함수로 붙여 `run_all.py`의 같은 표에서 비교
- 모든 실험은 "바꾼 것 · 검증 점수 · 채택 여부" 한 줄로 기록. 기각한 실험도 보고서 재료

### 위험 요소
- **테스트 구간에 휴무·재가동이 없음** → 증강·파생 피처의 기여가 테스트 MAE에 안 보임. 전환 구간 평가 항목으로 보여줄 것
- **튜닝 과적합** → 복잡한 모델을 더할 때 같은 일이 반복될 수 있음
- **생산계획 가정** → 방어 근거(일 단위 계획 7.2, 잡음 ±50%에도 6.9) 보고서에 포함
- **저감 효과는 모델 기반 가상 결과** → 실측 아님과 행동 범위 제한 명시
- **공개 저장소** → 마감 전 공개 상태. 보고서·발표자료에는 저장소 링크·계정명을 넣지 않는다(블라인드)
