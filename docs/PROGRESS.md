## 5. 성능 끌어올리기 실험

### 예측 오차의 바닥 (누수 제거 후)
- 레짐 전환 LightGBM을 시드만 바꿔 5번: 테스트 MAE 6.56~6.78 (평균 6.68)

### 해석

- **DiCE 반사실**: 예측 ≥ 185인 테스트 5시간 모두 해를 찾았지만, 목표수요 아래로 내리려면 해당 시간 생산을 중앙값 **88%** 줄여야 한다 → 생산량 조절은 약한 레버
- **누수 CV 시연**: 무작위 K-fold MAE 11.24 vs 복사 그룹 묶음 16.43 (약 32% 과소평가)

### 래칫 위험 강화학습 (`src/ratchet_rl.py`, `outputs/ratchet_rl/`)
- 세계 모형을 결정 기반 평가와 같게(실측 + 대리모형 변화분) 맞추고, 학습 구간 원본 가동일 61일에 교차적합 예측(평균·P75)을 붙임. **래칫 바닥을 그날 실제 최대수요 + U(−20, +15)kW로 무작위 설정**해 "넘을까 말까"인 날을 대량 합성
- **PPO 50만 스텝 → "아무것도 안 하기"로 수렴**(생산 이동 0%). 7/19에도 손해가 없지만 전력량요금 절감도 0. 탐색 중 잘못 옮기면 래칫 손실이 수백만 원, 잘 옮겨도 이득은 수만 원이라 가만히 있는 쪽을 배움
- **현장용 보호 규칙**(P75 상한 ≥ 바닥 − 5kW인 시간만 절반 미루기)은 7월에 한 번도 작동하지 않음 → **P75 상한조차 7/19에 바닥(206) 근처로 올라가지 않았다. 이 데이터의 예측으로는 7/19 피크를 미리 알 수 없었다.** P75 MILP의 7/19 손실이 작았던 것도 피크를 예견해서가 아니라 계획을 덜 공격적으로 바꿨기 때문 — 보고서에서 과장 금지
- **행동 복제(MILP P75 시연 3,000 에피소드, 정확도 85%)**: 시간별 행동을 흉내 내면 작은 실수가 누적돼 여러 시간을 엮는 MILP 계획이 무너짐. 7/19에 오히려 래칫을 올려 −157만 원. 처음에는 가동 끊김(시작 횟수 초과)이 벌점으로만 막혀 있어 끊김으로 피크를 피하는 편법이 나왔고, **행동 차단**(가동 중이면 0% 금지)으로 바꿔 막음
- **행동 복제 + PPO 미세조정**: 다시 거의 무조치(생산 이동 1%), 7월 −719원/일

|---|---|---|---|

### 확률 MILP — 오차 시나리오로 7/19 회피 (`src/stochastic_milp.py`, `outputs/stochastic/`)
- 예측 하나 대신 **평가 구간 이전 날들의 예측 오차 경로 전부**(7월 평가: 학습 구간 교차적합 61개 / 테스트: 학습+검증 79개)를 더한 최대수요 시나리오를 동시에 고려. 계획은 하나, 시나리오마다 래칫 초과 계산
- 목적: 전력량요금 + 기본요금 × 12개월 × 시나리오 평균 래칫 초과 (λ=0)

| 정책 (절감액, 클수록 좋음) | 7월 하루 절감(원) | 7/19(원) | 테스트 하루 절감(원) |
|---|---|---|---|
| MILP 평균 예측 | 16,804 | −151,899 | 9,269 |
| MILP P75 상한 | 24,050 | −21,465 | 9,269 |
| **확률 MILP (시나리오 평균, 전체 경로)** | **111,707 (완전 예측의 96%)** | **+1,634,756** | 8,241 (−11%) |
| 확률 MILP (CVaR 가중 λ=0.5, 1) | 10,979 | −169,502 | 7,921~7,940 |

- 7/19 래칫 갱신을 완전 예측과 똑같이 피함. 대가는 평상시(래칫에 묶인 테스트 기간) 전력량요금 절감 −11% → 163만 원짜리 사건 하나를 막는 보험료

- **CVaR는 오히려 실패**: 최악 10% 시나리오는 어떻게 계획해도 바닥을 넘어 계획을 바꿀 동기가 없음. "막을 수 있는 중간 위험"을 보는 시나리오 평균이 맞다

| **확률 예측 평가(CRPS)와 권고 확률** | 채택 | 분위수 예측은 MAE 대신 CRPS·포함률로 평가. 저감안은 "피크가 줄어들 확률이 충분히 높을 때만 권고"하는 규칙으로(TabPFN 분포 활용) |
| **모델 간 차이의 부트스트랩 신뢰구간** | 채택 | 날짜 단위 짝지은 부트스트랩으로 "제안 모델이 기준선보다 낫다"의 95% 구간 제시. 튜닝 과적합 사례처럼 작은 차이를 과대해석하지 않기 위함 |
| **가이드북 기준 모델 재현** | 채택 | KAMP 가이드북에 SimpleRNN(과거 168시간 → 1시간 뒤) 예시가 있는 것으로 보임. 평가위원이 아는 모델이라 비교표에 넣으면 설득력↑. 단, 가이드북은 1시간 앞 예측이라 하루 전 예측과 조건이 다름을 명시 |
| **누수 감사 자동화** | 채택 | 항등식 검사(공장인원, 평균), 시차 피처가 실제로 과거 값인지 assert, 복사 그룹이 학습·검증에 걸치지 않는지 검사를 코드 테스트로 |
| **ARIMA 계열 (SARIMAX)** | 오성민 트랙에 기준선으로 추가 | 2장 비교표에 전통 시계열 모델 칸이 비어 있음. 복제 구간·이중 계절성·레짐 전환 때문에 생산계획 외생변수를 넣은 SARIMAX + 롤링 예측이어야 공정한 비교 |
| **GBDT-LR (GBDT+신경망)** | 낮은 우선순위 | 원래 대규모 희소 CTR 데이터용. GBDT 자체가 리프 원-핫 위의 선형 모델이라 이득 작고, 리프 피처 수천 개 대 1,800행은 과적합. 인용 시 원형인 Facebook 2014 논문이 적절 |
| **강화학습** | **배진형 트랙으로 진행 (당일 실시간 수요 제어 형태)** | 하루 전 스케줄 재배치는 최적화로 충분해 설득력 약함. 당일 시간별로 관측 수요를 보며 남은 생산을 미루는 문제는 순차 결정 + 불확실성이라 강화학습이 맞음. 환경은 예측 모델 + 잔차 분포 시뮬레이터. 무조치·고정 규칙·탐욕 최적화와 같은 표로 비교 필수. 모델 허점 공략 방지를 위해 행동 범위 제한 |

## 8-2. 문헌·기법 조사 선별과 배정 (9/30)

세미나 메모(의사결정 학습, LLM 기반 시계열, 행렬분해·최적화)와 문헌 조사 보고서에서 이 데이터·이 대회에 쓸 만한 것만 골랐다. 기준은 세 가지다. ① 데이터 크기(원본 학습 약 1,800행, 텍스트 없음)에서 돌아가는가, ② 평가표 장에 수치로 기여하는가, ③ 10/8까지 끝나는가.

**우선순위**: 필수 = 10/3 통합 전 반드시 / 권장 = 10/5까지 / 선택 = 여유 있을 때만

### 배진형 — 결정 쪽 (강화학습 트랙에 붙임)

| 항목 | 우선순위 | 내용 | 쓰이는 장 |
|---|---|---|---|
| **한전 기본요금 래칫 구조** | 필수 | 기본요금 적용전력 = 직전 12개월 중 동계(12·1·2월)·하계(7·8·9월)·당월 최대수요 중 최댓값. 데이터 최대 222가 1·3·6·7월에 이미 찍혀 있어 8~9월 피크 저감의 기본요금 한계가치는 0에 가깝다 → 보상·절감액은 전력량요금(TOU) 중심, "래칫 갱신 위험"은 별도 지표로. 요금 단가와 데이터의 전기요금(계절) 값(109.8/167.2/191.6) 대응은 2021 요금표로 직접 확인 | 4장 |
| **래칫 인지 MILP 부하이동 (predict-then-optimize)** | 필수 | 결정변수: 시간대별 생산 배분·가동 시각. 목적: TOU 전력량요금 + 기본요금 단가 × max(래칫값, 당월 피크) + 인건비(1.0/1.5배). 최대값은 보조변수로 선형화. OR-Tools/PuLP로 소규모. **강화학습의 가장 강한 비교 기준선**(기존 계획의 "탐욕 최적화" 자리) | 4장, 5장 |
| **결정 기반 평가 (decision-focused evaluation)** | 필수 | 예측기(LightGBM·TabPFN·SARIMAX·Chronos-2)를 MAE가 아니라 "그 예측으로 짠 계획의 실제 비용 regret"으로 비교. MAE 순위와 결정 비용 순위가 다를 수 있음을 보인다. 근거: Elmachtoub & Grigas(2022) SPO. 결정 손실로 **학습**까지 하는 것은 기간상 제외(후속 연구가 SPO 단독 학습의 이득이 일관되지 않다고 보고) | 2장, 5장 |
| **비용가중 평가** | 권장 | 놓친 피크 1건의 비용 = 래칫 인상분 × 12개월 기본요금. F1 대신 비용 기준으로 경보 임계값 선택 | 3장, 4장 |
| **TOU·피크·인건비 삼중 상충 시나리오 표** | 권장 | 저가 시간대로 몰면 피크가 오르고(배치 제조 MPC 연구), 야간·주말은 인건비 1.5배. "피크 X kW 저감 시 절감액 vs 추가 인건비" 표로 제시 | 4장 |
| **시나리오 기반 확률 최적화 (CVaR)** | 선택 | 오성민 트랙의 분위수·경로 시나리오를 MILP/강화학습에 넣어 최악 꼬리 비용까지 관리 | 4장, 5장 |
| **롤링 원점 평가 + 일 단위 부트스트랩 / Diebold-Mariano** | 권장 | 평가 틀 담당으로서 테스트 일수를 늘리고 모델 간 차이에 신뢰구간 부여(기존 계획의 부트스트랩 항목 확장) | 2장 |

### 오성민 — 예측 분포 쪽 (TabPFN 트랙에 붙임)

| 항목 | 우선순위 | 내용 | 쓰이는 장 |
|---|---|---|---|
| **Chronos-2 zero-shot (생산량 공변량 포함)** | 권장 | TabPFN과 같은 "사전학습 모델" 비교군. 공변량(생산계획)을 넣을 수 있는 버전만 의미 있음. 복제일 제거 후 평가 필수. TabPFN과 같은 재현성 조건(오프라인 가중치, 라이선스) | 2장, 5장 |
| **컨텍스트 길이 민감도 (7/14/28일)** | 권장 | 복제일을 빼면 실효 이력이 수십 일이라 사전학습 모델 성능이 컨텍스트 길이에 민감할 수 있음. TabPFN·Chronos-2에 함께 적용 | 2장 |
| **LightGBM 분위수 회귀 (τ = 0.5, 0.9, 0.95)** | 필수 | 결정 기반 평가용 분포 파일의 LightGBM 버전. 현재 P90만 있음 → 분위수 확장. (기존 계획상 배진형 담당이던 LightGBM 분포 파일을 오성민이 분위수 비교와 함께 맡는다) | 2장, 5장 |
| **적응형 컨포멀 예측 (ACI / AgACI)** | 권장 | 지금의 분할 컨포멀은 포함률 83% → 97%로 과보정. 분포 이동(9월 등)에 맞춰 보정량을 갱신하는 ACI로 90%에 맞추기. 근거: Gibbs & Candès(2021), Zaffran 외(2022) | 5장 |
| **피크 크기 + 시각 동시 확률 예측** | 권장 | 일 피크의 크기 분포와 **발생 시각**(시간대 블록 또는 15분 슬롯)의 확률분포를 분위수·경로에서 산출. 평가: 임계 초과확률의 Brier·신뢰도 곡선, PR-AUC, 피크 시각 오차와 ±1슬롯 적중률. 문헌상 크기와 시각을 함께 다룬 연구가 적어 차별점 | 3장, 5장 |

| **누수 분류 체계 정리 (모델 인포시트)** | 필수 | Kapoor & Narayanan(2023) 분류에 맞춰 우리 데이터의 누수를 정리: 공장인원·평균 항등식(예측 시점 불가 특징), 복제일(훈련·테스트 중복), 생산량 = 계획 가정(실적이면 누수). 1장 부록. 모든 지표를 "원본일 기준"으로 보고하는 원칙도 여기서 명시 | 1장 |

### 함께
- **5장 서사**: "분포를 만드는 모델(TabPFN·Chronos-2·LightGBM 분위수) × 분포로 결정하는 방법(MILP·강화학습)"을 결정 기반 평가 하나의 표로 묶는다.
- **인용 규칙**: 보고서에 인용하는 논문은 DOI·원문으로 재확인. 2026년 arXiv 논문은 보조 근거로만. 공개 저장소 수치는 검증 방식 차이를 명시하고 기준선으로만 인용.

### 쓰지 않는 것과 이유

| 항목 | 이유 |
|---|---|
| LLM 기반 시계열(LLMTime, Time-LLM), 시계열+텍스트 멀티모달(Time-VLM, semantic 페어링) | 이 데이터에 텍스트가 없고, 원본 약 1,800행으로 대형 모델을 붙일 근거가 없음. 수치 토큰화는 연산 관계를 못 다룬다는 한계도 세미나에서 지적됨 |
| TimesNet, LSTM-AE + XGBoost 등 딥러닝 | 데이터가 작아 과적합 위험이 크고 기간 내 튜닝 부담. 사전학습 모델(TabPFN·Chronos-2)로 대체 |

| 극값 이론(EVT/POT) | 피크 사례가 수십 건이고 산업 부하 적용 논문을 확보하지 못함 |
| 역최적화 기반 생산 스케줄 식별 | 생산계획이 이미 주어져 있어 불필요, 합성 데이터 기반 연구 |
| 외부 한국 공장 데이터(Lee 외 2022)로 일반화 검증 | 논문용. 대회 기간 내 범위 밖 |

## 9. 앞으로의 계획

### 역할: 강화학습 × TabPFN, 서로 보완하는 구조

두 트랙은 **"예측 분포를 만드는 쪽"과 "그 분포로 결정을 내리는 쪽"**으로 맞물린다.

```
오성민 (TabPFN)                           배진형 (강화학습)
하루 전 예측 분포 ─────── ① 시나리오 ──────▶ 실시간 수요 제어 환경
 (시간별 분위수)                             (예측 + 불확실성으로 에피소드 생성)
        ▲                                             │
        └────────── ② 결정 기반 평가 ─────────────────┘
          "어느 예측기를 써야 피크를 더 줄이나"로
          TabPFN vs LightGBM을 MAE 밖에서 한 번 더 비교
```

- **① 시나리오 공급**: TabPFN의 예측 분포(분위수)를 강화학습 환경의 불확실성으로 쓴다. 지금 환경 후보(LightGBM + 잔차 부트스트랩)와 비교할 수 있다.
- **② 결정 기반 평가**: 같은 정책을 LightGBM 예측으로 돌릴 때와 TabPFN 예측으로 돌릴 때의 피크 감소를 비교한다. 예측 오차(MAE)가 바닥이라 차이가 안 보이는 두 모델을 **"현장 결정에 얼마나 도움이 되나"**로 다시 가른다. 5장 차별성의 핵심 이야기다.
- ③ TabPFN이 불확실하다고 본 시간대(분위수 폭이 넓은 시간)는 강화학습 정책이 보수적으로 행동해야 할 구간이 된다. 3장 오류분석과 4장 운영 절차를 잇는 고리다.

**배진형 — 강화학습 트랙 (3장 피크 조건, 4장, 6장)**
- 피크 발생 조건 분석: 시각·요일·생산량·인원·계절별 190 초과 빈도. 강화학습의 상태·보상 설계 근거이자 3장 재료
- 실시간 수요 제어 환경(gym 인터페이스)
  - 상태: 현재 시각, 오늘 누적 최대 수요, 남은 생산량, 앞으로의 예측·분위수
  - 행동: 이번 시간 생산 비율(예: 100/70/40%)과 **가동 시각 이동**(설비 기동 지연). 전력은 생산량보다 가동 on/off에 더 반응하므로(경쟁 저장소 분석, 우리 DiCE 결과와 일치) 시각 이동이 핵심 레버. 미룬 양은 뒤 시간으로
  - 보상: −일최대 수요 − 생산 미달 벌점 − 계획 변경 비용
  - 제약: 일 생산 총량 완수, 시간당 생산 상한(관측 최대치), 가동 시간대 안에서만 이동
- **공장 부하 시뮬레이터**: 기저부하 + 생산 비례 + 가동 개시 램프 + 요일·교대 + 잔차 분포. 데이터로 보정하고 LightGBM 환경과 교차 확인
- 비교 기준선: 무조치 → 고정 규칙(예측 ≥ 190이면 30% 미루기) → **래칫 인지 MILP**(8-2절) → 강화학습(PPO 등)

- 모델 간 차이 부트스트랩 신뢰구간, 누수 감사 테스트(항등식·시차·복사 그룹)

- 최종 예측 모델 정리(레짐 전환 LightGBM), 평가 항목 추가(운전 상태 전환 구간, 생산조건별 오차)

- **공개 저장소** → 마감 전 공개 상태. 보고서·발표자료에는 저장소 링크·계정명을 넣지 않는다(블라인드)

## 11. 오성민 Phase 1 — joint uncertainty와 decision propagation (2026-10-04)

최종 연구 목표를 **BEST FORECASTER → BEST UNCERTAINTY MODEL → BEST DECISION / CONTROL POLICY**로 명확히 한다. 이번 `regime_ens` 고정은 uncertainty 효과를 분리하는 실험 통제이며 최종 forecaster 확정이 아니다. Phase 2에서는 최고의 forecasting 성능 모델/단순 앙상블을 찾는다.

### Leakage와 실험 조건

- TRAIN 1/8~7/15, VALID 7/16~8/15 유지. TEST 학습/평가/선택은 이번 실행에서 하지 않았다.
- 기존 GroupKFold를 우회하고 strictly past-only expanding rolling origin으로 원본 가동일 residual을 생성했다. 원본 훈련일 14일 warm-up, 최대 14일 block, 실제 fit 종료 timestamp를 각 residual에 기록한다.
- residual은 49일 × 24시간, 타깃별 1,176행이다. TRAIN 후보 189일에서 복제 113일, 휴무 13일, warm-up 12일, 계획 누락 2일을 제외했다. 사용 기간은 1/28~7/14, 적합 origin은 7개다. `training_end_date >= forecast_date` 위반은 0건이다. 제외 날짜 전체는 `train_day_audit.csv`에 남겼다.
- VALID 원본 가동일 18일(7/19 제외 시 17일), 휴무 12일/복제 1일 제외. Forecaster와 surrogate를 모두 TRAIN만으로 적합했다. 테스트 이전이라도 VALID target으로 surrogate를 적합하는 기존 경로를 사용하지 않았다.
- 기존 features/config/복제 저가중치 champion은 유지했다. 과거 champion hyperparameter의 VALID 튜닝 이력, 실측 기상을 예보로 간주하는 가정, 반사실적 surrogate 비용은 여전히 연구 한계다.

### 공동 residual 구조

49일은 1,176개 독립 sample이 아닌 49개 daily vector다. 시간 의존성 및 날짜 의존성 때문에 통계적 유효 표본 수를 49로 확정할 수 없다. peak15 residual의 8~23시 내부 평균 correlation은 0.879, 1~6시는 0.971, 두 구간 간 평균은 -0.174다.

PCA PC1/2의 eigenvalue는 20,793.43/5,346.30 kW², 설명분산은 71.84%/18.47%(누적 90.31%)다. r=4는 95.51%, r=8은 98.32%다. PC1은 주로 8~23시 방향, PC2는 1~6시 방향, PC3는 17~19시와 20~23시 대비를 나타냈다. 이를 재가동 원인으로 단정하지 않는다. 높은 explained variance가 확률 점수나 decision 개선을 보장하지 않았다.

Raw covariance condition number는 6,719.43, Ledoit–Wolf는 116.74, OAS는 256.99였다. 실제 데이터 raw 최소 eigenvalue는 3.095로 양수였고 Cholesky 실패는 없었다. 구현은 near-singular 입력에 eigenvalue floor를 적용하며 low-rank stress test를 통과했다. Shrinkage의 수치 안정성 개선이 decision 개선으로 이어지지는 않았다.

### VALID 결과

Empirical/independent, Cholesky 3종, PCA Gaussian/bootstrap 각각 r=2/3/4/5/6/8: 총 17개 config를 K=30/50 × seed=0/1/2에서 비교했다. 1,836개 stochastic 결정과 18개 oracle 기준선은 모두 optimal이었다. 동일 alpha=.9/lambda=0/요금/래칫/생산제약을 사용했다. Empirical은 과거의 24시간 path를 함께 추출하므로 **이미 dependence를 보존**한다.
